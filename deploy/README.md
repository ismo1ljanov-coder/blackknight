# Neon'ga API joylash (NEON_API_KEY bo'lmaganda)

Neon funksiyasiga `neon-bootstrap.mjs` joylangan: u `api/index.js`ni GitHub'dan **aniq commit (SHA)** bo'yicha yuklaydi.
Yangi API versiyasini chiqarish: faylda `S='...'` qiymatini yangi commit SHA'ga almashtirib, zip qilib Neon'ga deploy qiling.

NEON_API_KEY GitHub secret qo'shilsa, `.github/workflows/deploy-api.yml` to'liq kodni avtomatik joylaydi va bu yuklovchi kerak bo'lmaydi.
